# Our Coastal Escape

This repository contains only an encrypted static app, its generic unlock screen, and public installation resources. The trip information, illustrated artwork, and application source remain encrypted. Personal checkmarks and answers stay in each device’s browser.

The passphrase and decryption key are not stored in this repository. Built using StatiCrypt 3.5.4 (AES-256 with HMAC and 600,000 PBKDF2 iterations).
